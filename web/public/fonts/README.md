# Local Fonts

Latin WOFF2 subsets of Inter (normal, variable 400-900) and Barlow Condensed
(normal/italic, weights 700/900), downloaded from the Google Fonts CSS API.
The site uses local assets so initial rendering does not depend on Google's
stylesheet and font connections. Other scripts use the system font fallback.

- [Inter source and license](https://github.com/google/fonts/tree/main/ofl/inter)
- [Barlow Condensed source and license](https://github.com/google/fonts/tree/main/ofl/barlowcondensed)

The original SIL Open Font License notices are included in `OFL-Inter.txt`
and `OFL-BarlowCondensed.txt`. The fonts have not been modified.
